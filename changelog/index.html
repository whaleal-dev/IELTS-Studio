新增

  • 新增独立 Go＋bbolt 云备份后端：空间与摘要凭据、原子 KV 覆盖／删除、序号墓碑、全局滑动限流、请求／队列／磁盘保护，以及私有 Unix socket 人工导出。
  • 新增「设置 → 单词过滤 → 播放纯数字」，默认关闭；各处单词和词组播放跳过纯符号，数字候选可在开启后播放，旧词表位置保留。
  • 新增独立「版本记录」页面，按真实版本展示新增、移除、优化与修复，未发布内容单独标明。
  • 新增复习计划三至十五阶段自定义，保留默认六阶段，已有到期时间不变；减少阶段后的旧高阶段在下次有效通过时归入新末级。
  • 新增独立「听力挖空」模块，接入剑桥雅思 10～20 共 176 篇材料及原声映射，提供整篇作答、固定首次成绩、答案／译文揭晓、确认重做、本轮错题 TXT 和按篇保存／恢复。
  • 增加挖空练习与本地音频两篇操作说明、相关截图和播放快捷键；备份明确挖空覆盖范围与最低兼容要求，旧客户端不能据包版本判断兼容。

移除

  • 移除听力挖空前后五秒快捷键及配置，保留播放器按钮并兼容旧绑定资料；本地音频设置增加新标签资源入口，自动搜索「音频」。
  • 停止构建、链接和收录 182 个单词／听力章组页；保留听力挖空与其他模块，同步操作说明、流程图和八张截图。

优化

  • 全面校准操作说明，精简正文并更新当前界面截图；补齐分享、播放过滤、每日提醒、单篇音频下载及扩展预览，分享和相关设置提供直达问号。
  • 单词与听力正式接入带音频路径和来源数组的 JSON，运行音频继续使用 Git 静态资源；听力挖空读取逐篇明确云源，保留原有本地文件与目录播放。
  • 右上角新增分享入口，按整个网站或当前模块生成微信、小红书、抖音及通用的可编辑文案、本地 PNG 海报与正式链接；微信海报附二维码。
  • 设置增加可关闭的云端自动备份、邮箱登记、手动尝试、上传状态及恢复凭据保管；逐键序号、确认时间与删除标记同事务保存，游标有界上传当前变更，恢复时补齐删除差集。
