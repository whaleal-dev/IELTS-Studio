网站与设置

本文链接（可复制或分享）

每篇说明都有可收藏、刷新和分享的独立地址。切离学习模块会暂停播放和听力计时，返回后手动继续。

从哪里进入

顶部切换六个学习模块；从「网站地图」进入「关于作者」查看简历、自愿捐赠与开发需求联系方式，功能旁问号可查对应说明。

操作步骤

  1. 点击顶部「单词」「听力」「同义词」「单词播放」「音频播放」「资源下载」；各页面使用固定路径，根网址默认单词。
  2. 切回已访问模块，核对当前位置后按需继续播放或练习。
  3. 打开「网站地图」，从模块卡片、「内置章节与分组」、三篇「实用教程」、「全部操作说明」或下方「关于作者」进入目标页面。
  4. 在「搜索操作说明」输入关键词；窄屏先展开「章节目录与搜索」，点击目录结果展开并定位问题。
  5. 总览中用「展开」「收起」控制各问题；阅读后用页顶返回按钮或浏览器前进、后退导航。
  6. 分享时点击「单独阅读（可复制或分享）」，复制独立文章地址；文章内也提供「本文链接（可复制或分享）」。

目录搜索与阅读状态

搜索标题、正文和图注，多个关键词须在同一篇中全部匹配；只过滤目录，不隐藏总览其他问题。搜索、展开状态和阅读位置按浏览历史条目在内存中保留。独立文章始终展开，通过「全部操作说明」回到总览。

独立地址与旧入口

文章地址为 help/章节ID/，例如 help/audio-player/；部署时位于本站目录下，支持直接访问、新标签页与刷新。原 help/#章节ID、?page=help#章节ID 仍定位总览问题，?page=help&topic=章节ID 进入独立文章。链接不携带词库、学习记录或来源草稿。

内置章节与分组公开页

内置单词和听力的章页展示分组目录，组页展示对应词表，可独立访问、刷新和分享。点「前往学习此章节／分组」只定位学习范围，保留当前任务、答案和草稿，仍须按学习页提示开始或加载分组。词表加载失败时在原页点「重试」；个人词库、自定义语料和个人记录不在公开目录中。

切页与保存

已访问模块在当前应用中保留状态，隐藏后不响应练习快捷键，返回不自动播放。关闭或刷新前仍须检查保存提示；音频播放的文件、顺序和进度仅临时保留，刷新需重新导入。问号在新标签页打开对应单篇，原标签页保留地址、任务、输入、候选及已打开的弹窗，切回原标签页继续。打开新标签不会主动暂停原页播放或听力计时，阅读前请主动暂停。忙碌时问号暂不可用；旧同页帮助导航返回后，危险操作仍须重新确认。

找不到说明

无搜索结果时缩短关键词或点击「清空搜索」。显示「未找到对应说明，请从目录选择」时改从目录进入；旧目录或旧 HTML 地址不再兼容，请从网站地图重新收藏。
