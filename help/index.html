单词学习

单独阅读（可复制或分享）

按分组学习单词，可选单词卡片、中文选择题或听写；普通搜索限当前学习词库。

从哪里进入

点击顶部「单词」→「开始学习」，在上方选择词库、章节和分组。

操作步骤

  1. 在「学习词库」选择内置或个人词库，再选择「当前章节」。
  2. 点击分组按钮定位；与当前任务不同时，再点「学习所选分组」，核对练习卡片的分组名称和位置。
  3. 用「单词卡片」查看词义；用「中文选择题」点选释义；用「听写」听音后输入完整拼写，点击「提交答案」或按 Enter。独立作答前先按下方说明隐藏材料。
  4. 用「上一个」「下一个」切词，「开始播放」连续听音。搜索英文、释义或音标后，点词条查看，或用「练习搜索结果」练全部匹配项。
  5. 结束前确认顶部显示「本地已保存」。切换模块或在原标签页查看说明会暂停播放，返回后手动继续。

浏览词库与地址定位

在「我的词库」点「查看章节」，展开「主题章节」查看分组和自评掌握进度，点分组才开始学习。无定位地址时，首次显示当前学习词库，之后保留独立浏览范围。地址和前进／后退只定位并暂停，保留任务与未保存内容；重选当前章节也保留本轮和位置。个人词库地址仅在保存它的浏览器来源可用。

手动发音与连续播放

发音按钮或「重播」只读当前词一次；「开始播放」按设定次数连续播放。自动播放中重播也只读一次，随后下一词恢复设定次数。

播放设置

  • 展开「播放设置」选择英文发音人。有匹配本地 MP3 的词优先用录音，其余用浏览器英语语音；换发音人不改变本地录音。
  • 单词、词组速度分别为 0.6～2 倍，互不叠加。去掉首尾空白后仍含空格的条目按词组播放，例如 take care of。
  • 播放间隔为 0～5 秒，每词完成指定次数后再等待；0 秒直接继续。每词次数为 1～5 次，包含首次，仅用于连续播放。
  • 设置仅在本模块保存。本地 MP3 变速即时生效，浏览器语音用下一次发音时的参数。发音失败时按提示重播或换可用英语发音人；已有录音失败不会改用合成语音。

显示与作答规则

卡片的「隐藏单词」同时隐藏音标，仍可发音；卡片和听写共用释义显隐，显示释义不触发查看材料标记。选择题可按数字 1～4，提交后不重复作答；个人词库释义不足时补用内置库的不同释义。听写忽略大小写、首尾和连续空白，统一常见弯引号，仍须正确拼写，不能答近义词。提交后手动「下一个」。

笔记与冲突处理

展开「我的笔记」输入后自动保存；新笔记上限 400，已有长笔记保留。普通学习初次默认展开，手动收起后切词、切组、切模式保留选择，刷新重新默认展开。出现「另一页面已更新笔记」时先比较两份：「使用已保存笔记」放弃草稿，「用当前草稿覆盖」替换已保存版本。未确认前两份均保留，不要反复刷新消除提示。

搜索范围

普通搜索查当前学习词库的全部章节和分组。「显示更多词条」只增加展示，「练习搜索结果」包含未展开项。找不到时先核对词库，再试较短英文或中文释义。难词复习和学习统计汇总全部当前词库。

独立作答与本轮结果

选择题和听写按本轮首次作答统计，累计记录另存。本轮词表默认显示，显示词表或非空笔记后答对按巩固处理。独立作答前，先隐藏词表、收起含内容笔记，再进入未查看材料且无可见冲突原文的新题；当前题重新隐藏材料不能撤销标记，详见「首次作答、巩固与错词复练」。刷新可恢复已保存位置，临时答题结果清零。

读取或保存失败

「尚未保存」时保留页面并「重试保存」；「读取失败」先「重试读取」。保存冲突须核对提示和草稿，笔记另有独立确认。资料仅保存在当前网站来源的当前浏览器，重要记录请做完整备份。

单独阅读（可复制或分享）

难度为 0～10，表示复习优先程度；自评掌握单独记录。

从哪里进入

在「单词」→「开始学习」的练习卡片下方，查看难度和自评掌握按钮。

操作步骤

  1. 选中一个词，查看当前「难度」数值。
  2. 点击「－1」「＋1」或「难度＋3」调整，数值保持在 0～10。
  3. 点击「标记自评掌握」，核对标记变化；难度不随之改变。
  4. 确认顶部显示「本地已保存」；失败时保留页面并重试。

答题怎样改变难度

新词默认 0。选择题或听写答错加 3，最高 10；同题不重复增加。答对不会自动降低难度，学习次数和正确率也不代表自评掌握。

自评标记

「取消自评掌握」只取消手动标记，不修改难度、答案结果或复习阶段。

难度与到期复习

难度大于 0 的词进入难词复习。从 0 人工提高后立即待复习，不增加错误次数或制造实际答错时间。已有新计划时，正数之间加减不重置排期；降至 0 停止排期，保留历史。详细排期见「错题与间隔复习」。

例子

难度 8 的词答错后变为 10，再标记自评掌握，难度仍为 10。

单独阅读（可复制或分享）

筛选全部当前词库的难词，可提前温习，也可只练已到期的词。

从哪里进入

点击「单词」→「难词复习」，无需选择词库。

操作步骤

  1. 核对「全部词库」范围，以及词条的词库、章节和分组来源。
  2. 设置搜索、难度范围、全部／到期词和排序，核对筛选词数与到期标记。
  3. 点「练习筛选结果」练全部匹配项，或点「开始到期复习」仅练其中到期词。
  4. 在卡片作答并查看本轮结果。整理清单时返回复习页「导出难点词 CSV」，在浏览器下载列表核对文件。

范围与来源

默认难度 1～10，最低设为 0 可查看难度 0 的词。练习包含未展开项，到期复习也遵守当前搜索和难度范围。同英文跨词库、章节或分组分别记录；复习中心指定词库的到期入口仍只练该库。

到期复习

到期任务默认听写、隐藏词表并收起笔记，可切换中文选择题，普通显示偏好保留。没有到期项时核对筛选条件和下次复习时间；读取失败先重试读取再开始。只有到期且首次独立答对才推进，自评掌握不推进，具体规则见「错题与间隔复习」。

刷新与排期

跨库复习和错词复练刷新后，静默恢复实际词表与位置，临时结果清零。人工调难度、实际答错对排期的影响见「单词难度与自评掌握」及「错题与间隔复习」。

例子与导出边界

筛选出 20 个难词，其中 5 个到期，到期复习只练这 5 个。CSV 只导出当前筛选内难度大于 0 的词，逐词标明词库、章节、分组，不含笔记，不能替代完整备份。

难词复习流程

  • 筛选全部词库

    无结果时调整搜索或难度。

  • 选择全部结果或到期词

    练习包含未展开项；尚未到期可提前温习或等待。

  • 开始练习，按需导出清单

    CSV 不能恢复学习记录。

单独阅读（可复制或分享）

学习情况显示当前词表的累计记录；未学词重排只看本轮是否已浏览或练习。

从哪里进入

在「单词」→「开始学习」进入普通分组，查看「词表学习情况」和「本轮词表」。

操作步骤

  1. 浏览普通分组，在本轮词表中确认当前项与已学位置。
  2. 点「顺序排列未学词」恢复待学词原词序，已学词在前，当前词不变。
  3. 待学词至少两个时，点「乱序未学词」仅打乱后续待学项，再用「下一个」继续。

重排保留什么

重排会暂停播放，保留当前词、输入、反馈与首次结果，不增加学习次数。两种按钮只用于普通分组；搜索、难词复习和错词复练不提供。

累计与本轮的区别

「已浏览或练习」和自评掌握取累计记录；待学词按本轮判断，不能用累计已学数量推算。

查看与隐藏本轮词表

列表展示全部词条，标记当前词及各词的难度、自评掌握。点击词表不跳题或试听，须用练习卡片、快捷键或连续播放切词。「隐藏本轮词表」收起列表，保留标题和词数；重新显示不改位置，但选择题或听写查看后答对按巩固处理。

例子与刷新

昨天学过的词，本轮未浏览仍可重排。刷新可恢复已保存顺序和本轮已学位置，临时答题结果清零。

单独阅读（可复制或分享）

词条统计汇总全部当前词库；每日积累保留历史，按设备当地日期计算。

从哪里进入

点击「单词」→「学习统计」，无需选择词库；当日汇总也可在「开始学习」的「今日积累」查看。

操作步骤

  1. 查看前三张卡片：已浏览或练习、自评掌握、难度大于 0 的词数。
  2. 查看连续学习及最近 7／30 天图表，了解全部词库的每日积累。
  3. 返回「开始学习」看「今日积累」及当前时区，区分学习词数与复习记录次数。

统计范围

包含内置及全部当前个人词库，同英文跨词库、章节或分组独立计数。导入解析、保存及仅浏览或定位范围不计学习；点击「开始学习」「学习所选分组」或词库分组卡片进入学习后，会记录当前词的浏览。删除词库后当前词条数减少，历史每日汇总保留。

日期与次数

每日学习按词条去重，「复习记录次数」可对同词累计多条。已有日汇总不因设备时区变化重分；顶部日期用北京时间，与每日统计可能不同。

为什么数字不同

「词表学习情况」只看当前词表，「学习统计」看全部当前词库，「本轮结果」只记本轮首次作答。一个词可同时已浏览、自评掌握且难度大于 0；三种状态独立，不是互斥分类。

例子

今天多次学习同一词，今日学习词数只计一个；若产生多条复习记录，复习记录次数可大于一。

单独阅读（可复制或分享）

将 CSV／TXT 保存为新的个人词库；同名另加序号，不覆盖旧库，也不恢复学习记录。

从哪里进入

点击「单词」→「我的词库」→「导入词库」；模板在「文件格式示例」。

操作步骤

  1. 参照下方字段表和样例，保存 UTF-8 CSV 或 TXT；原五字段继续适用，可增加 tags，空字段保留逗号占位。
  2. 选择或拖入一个文件，等待词条、章节、分组及预览出现。
  3. 核对预览、标签文本和「词库名称」；有字段错误时按行号修正文件，重新选择。
  4. 点「保存为新词库」，等「已导入」及加入我的词库提示；失败时保留解析内容并「重试保存」。
  5. 点「开始学习」进入新库，再选章节、分组；需切换时点「学习所选分组」。也可在「我的词库」点「查看章节」，展开后点分组学习。

导入字段说明

规模、顺序与去重

单文件最多 2 MiB，去重后最多 5000 个词条。章节及章内分组按首次出现顺序展示；仅同章同组内英文规范化后、释义、音标和标签全同的词条去重。标签键顺序不影响比较，缺失、空列及 {} 等同无标签；跨章组或标签不同的同词保留独立身份与学习记录。

解析与保存的区别

预览含文件名、名称、词数、章节数、分组数、重复数及前十条词条；有标签时显示 JSON 文本供核对，当前没有标签徽章、筛选或编辑。录音／浏览器朗读数指词条数量，后者不是发音人数。关闭或取消未保存的预览不创建词库；解析和保存不计学习，点击「开始学习」后进入练习，仍需主动发音。词库只保存在当前网站来源的当前浏览器，重要资料请完整备份。

文件不合格时

确认扩展名 CSV／TXT、UTF-8 编码（可带 BOM），按行号检查字段和引号。空文件、无效编码、超限或字段错误须修正后重选；解析或保存中等待完成。不要上传同义词无表头分组文件、纯英文播放词表或完整学习备份。

CSV 与 TXT 的字段顺序

均用英文逗号分隔并保留空值占位。CSV 首行必须包含原五个字段名，可选增加 tags 表头，五列或六列均按名称读取、列顺序可变；有 tags 表头时每条记录必须为六列，空标签也保留该列。TXT 无表头，每条按表中顺序填写五字段或六字段，第六字段是 tags。旧四字段和竖线格式不支持，空值规则见字段表。

字段中有逗号、双引号或换行

CSV 和 TXT 均用英文双引号包住含逗号或换行的完整字段，字段内的双引号写成连续两个。下例只导入 apple，释义保留为「苹果,苹果树」；CSV 另须补五字段表头。

apple,"苹果,苹果树",/ˈæp.əl/,默认章节,第一组

听力练习

单独阅读（可复制或分享）

听音设置播放间隔，听写设置答题限时；听写计时从音频结束后开始。

从哪里进入

打开「听力」练习页，在「选择分组」下方选择「听音／听写」并设置参数；开始后须先结束练习才能修改。

操作步骤

  1. 选择原分组；出现「加载所选分组」时点击加载，再选「听音」或「听写」。地址和前进／后退只定位并暂停，保留原任务、语料与答案；有进行中的任务须先结束才能加载。
  2. 设置语速、间隔／限时，点击「开始练习」播放音频；本轮进度沿用已保存的显隐选择。
  3. 听写时输入完整单词或词组，按 Enter 或点击「提交答案」。音频结束后才开始限时；限时为 0 不自动超时，答对仍自动进入下一题。
  4. 出现「本题超时」后查看答案，手动点击「下一个」，末项点击「完成本轮」；普通答错按下方规则继续。
  5. 点击「暂停练习」冻结音频和计时，点击「继续练习」恢复。暂停时参数仍锁定，先「结束练习」再修改。
  6. 自选内容须先结束练习，再编辑「原语料」，来源变为「自定义语料 · 手动粘贴」。开始后核对未匹配、分组及缺音频提示与实际条数；自定义内容不计完整分组成绩。
  7. 音频报错先点发音按钮重播，仍失败再「跳过音频」。跳过不记实际答错，但本轮不计分组成绩；读取或保存失败保留页面并按提示重试。

听音与听写参数

  • 单词和词组分别设置 0.4～2 倍速，内部有空格的英文按词组速度播放。听力使用本地原声，缺失或失败不会改用合成语音。
  • 听音可选顺序或乱序，「每条播放次数」「本轮循环次数」均为正整数，没有 20 次上限。例如每条 2 次、整表 3 次，表示每条读两遍后切换，整表共播放三轮。
  • 听音「播放间隔」为 0～60 秒，0 秒需手动继续；听写在同一位置设置「答题限时」，不应用听音顺序、每条次数和整表循环，每题播放一次，可主动重播。结束练习会中止本轮，保留已有逐词记录，不补算完整分组成绩。

自定义语料

手动编辑原语料后立即切换为「自定义语料 · 手动粘贴」，保留输入；仅支持当前听力语料库内的单词或词组。用换行、中英文分号或逗号分隔，保留短语空格，重复内容合并。开始时过滤不存在、不属于所选组或缺音频的条目，没有可播放语料则不开始。要计原完整组成绩，重新选择该组且不修改语料；朗读任意英文词表可用「单词播放」或「音频播放」。

本轮显示

本轮语料用紧凑词表展示全部条目；听音可切换拼写显隐，听写未作答词的拼写始终遮蔽。「显示本轮语料／隐藏本轮语料」只切换拼写，不收起列表卡片。收起「本轮进度」会使整张卡片隐藏、练习区向右扩展，用「展开本轮进度」恢复。显隐选择会保存，不改变播放与计时；错词本的列表分页保持独立。

判题与自动推进

判定忽略大小写、首尾及连续空白，统一常见弯引号，仍需拼写正确；空输入不判错，有效提交后本题结果固定。普通答错或「显示答案」后，正限时会自动继续：音频未结束则从结束起等完整限时，已结束则从判错起重新等完整限时，也可手动继续；限时为 0 则手动继续。超时始终停留。例如限时 5 秒，音频结束才计这 5 秒，超时后点击「下一个」。错题可完成后复练。

重播与暂停

需要再听时点击「重播」。暂停状态不接受提交；打开设置、学习记录，或在原标签页查看操作说明、离开模块，都会暂停，关闭或返回后须主动继续。问号打开新标签前，请先主动暂停练习。

读取、保存与音频失败

启动时缺音频会过滤该条，原组因此失去完整分组资格；播放中失败按步骤 7 处理。顶部「读取失败」表示已有记录未读成功，可临时练习但不会保存，先「重试读取」；练习区「重试读取复习设置」保留当前输入和待保存答案，成功前不按空设置写排期。出现「尚未保存」时保留页面并「重试保存」，播放或判题成功不等于记录已保存。

计分条件与失败处理

选择原分组并完成全部语料，不要求全部答对，中途结束不计入。听音、自定义语料、子集、错词复练及跳过音频的练习不计入；原组启动时缺音频被过滤也不计。跳过不记实际答错。完成页符合条件却未保存时先重试保存，不靠重做一遍代替重试。例如原组 50 条须全部完成且未跳音频，只复练其中 5 条不会增加分组成绩。

五项指标

完整分组听写次数是完成轮数；累计正确率＝（听写总条次－错误总条次）÷听写总条次，平均成绩是各轮正确率的算术平均，最好／最差是单轮成绩。例如 10 条分组考 90％、100 条分组考 60％，累计正确率为 62.7％，平均成绩为 75％。

筛选、图表与分析

成绩按北京时间日期汇总。默认全部分组，左侧可按章节多选、搜索和已练／未练筛选；日期支持全部、近 7 天、近 30 天和自定义。图表在统计范围内另选对比组，默认最近练过的 3 组，合并／拆开保留选组；图表选组不改变左侧统计范围。缺练日期留空，未练组保留在成绩表、成绩显示「—」。分析区显示完整听写覆盖、薄弱分组与练习节奏；近期变化始终比较所选分组最近两段 7 天，不受顶部日期范围影响。

核对单组与键盘操作

刷新与完整组重测

历史数据不足

旧记录缺少最差单轮和每轮正确率之和，无法补算全部历史的最差／平均成绩。页面保留旧成绩，并显示新增统计的覆盖轮数与起算时间，覆盖不足时提示「历史数据不足」。这些统计支持刷新和完整备份恢复，新备份应使用支持其字段的版本恢复。

单独阅读（可复制或分享）

文件格式

新上传仅支持 UTF-8 TXT／CSV，均无表头、每行一组，忽略空行。TXT 用中英文逗号分隔；CSV 用英文逗号，含逗号或双引号的字段用双引号包围，内部双引号写成两个双引号。

容量与兼容

单文件最多 2 MiB，每批新文件与所选已有原文合计 10 MiB；合并词库最多 10000 条（含中文标签），单组最多 200 条，单条最多 200 字符。不合格时整批拒绝。含汉字词条只展示、不发音。新上传不接受 JSON；已保存的 JSON 原文仍可勾选加载，已有词库、笔记和完整备份继续读取。

播放参数与分组展示

  • 使用设备可用的英语语音。单词与词组速度分别为 0.5～2 倍；去除首尾空白后内部仍含空白的条目用词组速度，例如 take part in。

  • 保留组内顺序和重复词，所有词条平等展示。播放或切词会自动展开当前组，后续组可「显示更多同义词组」；居中开关默认关闭，开启后滚到当前组，切换不打断播放。

打开「音频播放」→「导入音频或词表」，选择录音及 CSV／TXT，逐行设置后用底部按钮播放。

操作步骤

  1. 多选录音及 CSV／TXT，每份占一行，单次及列表累计最多 100 份。超限、零字节、不支持的格式或文本检查失败时整批拒绝，保留已有列表。
  2. 录音选倍速，词表选英文发音人、单词／词组倍速。循环次数为 1～100 整数，包含首次；词表按整表遍数计算，每词每遍一次。有效参数自动记入历史。

速度与循环次数

  • 录音播放文件原声，编码须由浏览器支持，导入成功不保证能解码。普通倍速及词表两种语速均提供 0.5、0.75、1、1.25、1.5、1.75、2 倍。

  • 录音倍速立即生效；词表发音人与语速从下一次朗读生效。次数在当前录音遍或整表结束时判断，不截断词表。应用不开始播放、不重置断点，也不补播本轮已完成文件。

历史设置与文件身份

音频和词表合计记住最近使用的 1000 个身份，按类型、文件名、大小及最后修改时间匹配，兼容旧音频历史。元信息相同不证明内容相同，改名、大小或修改时间变化视为新身份。超限移出最久未用的历史，不改设备文件；重复行独立，下次导入采用最近有效用户修改，不回填已有行。历史纳入完整备份，清理缓存不移除。100 份列表、1000 份历史与每份 1～100 遍分别计算。

实际错误与人工标记

单词选择题／听写、听力听写有效答错会增加累计错误次数并记录时间，听力超时或显示答案也判错。空输入、浏览、播放、缺音频或跳过不记错；同题不重复累计，难度或等级已达 10 再错仍重新记录并排期。相同英文在不同词库、章节、分组或模块分别保存。

默认间隔与时间示例

六阶段默认为 20 分钟、1 天、3 天、7 天、15 天、30 天，第六阶段此后保持。10 月 21 日 10：00 答错，首次到期 10：20；到期独立答对后下次为 10 月 22 日 10：20，再通过为 10 月 25 日 10：20。若 10：10 提前答对，仍于 10：20 到期；10：15 再错则改为 10：35。时间显示使用北京时间，1 天按 24 小时。

保存设置何时生效

只有已成功保存的间隔参与排期；已有排期不追溯重算，新计划后续答错或到期通过才用新间隔。当前题固定使用进入时的设置，后续新题读取最新配置。打开设置会暂停播放与听力计时，关闭后须主动继续。

什么算通过

必须到期且首次独立答对。提前正确、查看材料后正确、自评掌握不推进或推迟到期；重新隐藏材料也无法恢复本题独立资格。听力未作答时，错词本当前已展开列表显示本题拼写也算看过材料；筛选隐藏或尚未展开的词不触发，提交后再查看不改变原资格。逾期只推进一级，从实际通过时间安排。保存重试沿用原答题时间；两个标签页完成同一排期只能推进一次，旧题正确不覆盖另一页新错误排期。

人工调整与旧资料

从难度或等级 0 人工提高到正数可立即待复习，不增错误次数、不造实际错误时间；新计划内正数加减不重置排期，降至 0 或移出错词本停止排期并留历史，再加入仍待复习。旧单词沿用原 12／24／72／168／360 小时规则，真实答错后转入新计划；旧听力正等级无排期者标为「历史待复习」，首次独立答对进入第二阶段。无实际错误时间的旧资料显示「历史未记录」，新人工加入显示「尚无实际答错记录」，不能用错误标记时间推算。

任务范围与刷新

按到期时间升序，同时间按难度／等级降序。单词遵守搜索和难度范围；听力遵守搜索、分组及筛选内有效勾选，分别显示到期总数和可播放数，缺音频不移出记录，子集不计完整分组成绩。每分钟、返回模块及窗口聚焦时刷新到期状态。任务默认隐藏材料不改变普通学习的显隐偏好；刷新遵守原模块恢复边界，不保证恢复临时答案。

个人词库的 tags 与稳定词条身份一起备份和恢复。旧词库、旧备份缺少标签时继续读取，不补写空标签；含 tags 新字段的备份须使用支持该字段的新版恢复。单词难点词 CSV 的导出范围不变，不能代替完整备份或作为可回导词库。

自动备份

默认每 3 天，可选 1～7 天；网站打开时检查到期，关闭期间到期则下次打开补执行一次。播放、练习、未保存编辑或设置弹窗打开时暂缓，网站关闭时不会后台下载。发起下载后重新计时，最近与下次时间使用北京时间；发起下载不等于文件已保存。频率读取异常用「重新检查」，保存失败用「重试保存」。

草稿或其他页面阻止操作

完整下载与恢复会暂停已访问模块，检查未保存编辑、读取失败、冲突和其他在线页面。先保存或处理冲突再重试；需要留草稿时用「保存未保存内容」，只收集当前页面已访问模块可取得的内容，不含其他标签页内存。其他页面未响应时，先保存并关闭它们，再用界面提供的重新检查入口，不要清除网站数据。

恢复中断的确认文字

按下方流程选择页面实际显示的入口：「继续恢复」须使用原备份并输入「继续恢复」；「取消本次恢复」输入「取消恢复」；「完成恢复」输入「完成恢复」。成功后不能一键撤回，找回原资料须重新导入恢复前下载的备份。

更换浏览器或访问地址

资料不会自动共享到其他浏览器或设备；localhost 与 127.0.0.1，以及不同协议或端口也分别保存。迁移资料须下载完整备份，再到目标地址导入。

备份恢复与中断处理

  • 下载当前备份并核对文件已保存
  • 选择要恢复的完整备份并核对范围

    校验失败不会替换原资料，请按提示更换文件。

  • 输入恢复备份并最终确认

    恢复替换全部学习资料与设置，不与现有资料合并。

  • 切换前失败或中断：按提示继续或取消

    继续须使用原备份；取消前若仍有导入预览，先点「取消导入」。中断后原资料又被修改时不能继续，须先取消本次恢复，再重新选择文件校验。

  • 切换后收尾失败：完成恢复

    备份已导入，点击「完成恢复」重试核验与清理，此时不能取消回到原资料。

  • 恢复完成并核对资料

    成功后不能一键撤回；找回原资料须重新导入此前下载的备份。

单独阅读（可复制或分享）

词库、笔记、记录和设置保存在当前浏览器及网站来源；缓存可重新生成。换浏览器、设备、协议、域名或端口不会自动共享资料。

从哪里进入

打开顶部「设置」，进入「存储管理」，查看学习资料、缓存占用及当前保存状态。

操作步骤

  1. 查看「空间使用情况」，区分学习资料和缓存；展开「详细信息」检查各模块状态。
  2. 读取失败时点击「重新检查」；正常清理后用量自动更新，空间估算不保证下次保存成功。
  3. 点击「清理缓存」，核对范围并输入「清空缓存」，再点击「确认清理缓存」；词库、笔记与学习记录保留。
  4. 保存失败时保留页面并重试；需要先留草稿副本时，进入「备份」→「保存遇到问题」→「保存未保存内容」。
  5. 展开「更多设置」，按需点击「减少浏览器自动清理」并查看结果；是否允许由浏览器决定，仍须定期备份。

清缓存与清除网站数据

「清理缓存」保留词库、导入原文、笔记、记录和设置，不能解决未保存的编辑冲突。取消或关闭确认后须重新确认。浏览器的「清除网站数据」会丢失学习资料，不应用来排查保存失败；重要资料先做完整备份。

其他页面阻止操作

遇到页面响应异常时才显示「其他学习页面已关闭，重新检查」。先保存并关闭其他学习页面，再输入「页面已关闭」并确认；系统仍会核对在线页面，正在使用的页面仍会阻止操作。

资料保护的限制

减少自动清理只是向浏览器申请保留资料，不能代替备份。「保存未保存内容」只导出本页能取得的草稿，不能作为完整备份恢复，详见「完整备份与恢复」。

单独阅读（可复制或分享）

建议搭配对应实体书学习，结合书中讲解与本站练习，巩固词汇记忆和听写能力。

从哪里进入

进入「单词」或「听力」时，符合条件会出现实体书提醒；点击「了解」或在操作说明目录选择本问题。

操作步骤

  1. 在提醒弹窗核对对应书名、书籍图片和资料来源。
  2. 点击「了解」阅读配套资料和提醒规则，再用「返回原功能」回到学习页面。
  3. 暂时收起用「关闭」；已购买对应书籍则点「已购买」，保存成功后关闭，该书不再提醒。

什么时候提醒

首次进入对应模块时提醒；此后距上次提醒满 10 天，再次进入该模块时才提醒。点击「关闭」或「了解」只收起本次提醒，不会永久关闭。提醒不会在播放或练习中途弹出；页面在后台或已有其他弹窗时，本次进入也不弹出，之后再次进入时再检查。资料来源和搭配实体书的建议不在学习页面常驻。

已购买后还会提醒吗

选择「已购买」并保存成功后，在当前浏览器、当前网站地址中不再提醒这本书；单词与听力分别记录，购买一本不会关闭另一本的提醒。若提示未能保存，请在弹窗中重试。

更换浏览器或网站地址后

提醒选择只保存在当前浏览器、当前网站地址中，不随完整学习备份迁移。更换浏览器、设备或网站地址，以及清除网站数据后，都不会保留原来的提醒选择。清除网站数据也会丢失个人词库和学习记录，请勿为了重设提醒而清除。
