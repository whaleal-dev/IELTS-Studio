听力练习

本文链接（可复制或分享）

听音设置播放间隔，听写设置答题限时；听写计时从音频结束后开始。

从哪里进入

点击顶部「听力」→「语料练习」，选择章节、分组和听音／听写模式；听写请使用电脑版浏览器。

操作步骤

  1. 点击「特别名词、形容词与副词、吞音连读、数字与信息、综合测试」章节按钮，分别对应第 3／4／5／8／11 章，自动选择该章首组；分组下拉保留跨章节搜索，不重复列出自定义项。「自定义语料」按钮会进入手动语料并展开编辑区。再选「听音」或「听写」；手机端仅支持听音，点击听写时显示「听写模式请使用电脑版浏览器」，三秒自动关闭。已有任务须先结束，待保存答案须先处理；切换被拦截时保留原任务、语料与答案。
  2. 展开「播放设置」调整单词／词组速度、听音间隔或听写限时，再点「开始练习」。面板首次收起，后续在当前浏览器记住展开／收起状态；展开与收起均完整显示全部速度、间隔、顺序、每条次数及本轮循环配置，发音人不在摘要内，收起不改变参数。
  3. 听写时输入完整单词或词组，按 Enter 或点击「提交答案」。「提交答案后直接下一个」默认开启，答对、答错和超时均立即进入下一题，不展示本题反馈，末题直接完成本轮；关闭后答对自动、答错和超时手动继续。音频结束后才开始限时；限时为 0 或无限时不自动超时，答对仍自动进入下一题。
  4. 主动点击「显示答案」始终记错并停留，手动点击「下一个」，末项点击「完成本轮」。超时同样记错，自动下一题开启时立即切题，不显示「本题超时」和正确答案；关闭时才停留展示答案并手动继续。
  5. 点击「暂停练习」冻结音频和计时，点击「继续练习」恢复。桌面听写缩至手机布局时自动暂停并保留答案，恢复桌面后手动继续。播放及暂停时可调整速度和限时，听写循环固定为 1，「听音顺序」须先结束练习再修改；修改参数不会自动恢复已暂停的练习。
  6. 自选内容须先结束练习，再点击「自定义语料」按钮或直接编辑「原语料」，编辑后切换为自定义语料并保留输入。开始后核对未匹配、分组及缺音频提示与实际条数；自定义内容不计完整分组成绩。
  7. 音频报错先「重播」，仍失败再「跳过这条音频」。跳过不记实际答错，但本轮不计分组成绩。结束前核对顶部保存状态；空间占用在「设置」→「存储管理」查看。
  8. 听写自然完成后在下方查看「答题详情」。「结束练习」先检查未保存作答，再弹窗确认；点背景不关闭，确认后本轮不可恢复、不计入分组成绩，取消或关闭保持暂停。核对正确率、每题单词、我的拼写与对错；按需点击「答题情况一键导出」下载 CSV，或点击「AI 一键诊断」复制后粘贴到 DeepSeek／ChatGPT。手动结束仅展示已答部分，不计入分组成绩。

听音与听写参数

  • 「单词播放速度」「词组播放速度」分别为 0.25～2 倍速、步长 0.05；默认分别为 1.00×、0.80×，含空格的英文按词组播放。使用本地原声，缺失或失败不会改用合成语音。
  • 听音可选顺序或乱序；「每条播放次数」和「本轮循环次数」均为 1～10 的整数。例如每条 2 次、整表 3 次，表示逐条读两遍，整表共播三轮；末项点击「进入下一次循环」或「完成本轮」。
  • 听音「播放间隔」与听写「答题限时」均为 -0.5～10 秒、步长 0.5 秒的滑条，负值档显示「无限」。听音 0 秒播完立即播放下一个，无限时手动继续；听写 0 秒与无限均不限时，正值最多 10 秒。听写每题播放一次，本轮循环固定为 1，循环输入不可修改，不使用听音顺序；需要时可重播，切回听音保留原循环设置。
  • 速度即时生效；听音每条播放次数用于下一条或重播，本轮循环次数即时更新，下调时至少完成当前循环。音频结束后修改间隔或限时，从修改时按新值重新计时：听音设为 0 立即继续、无限取消自动切题，听写设为 0 或无限取消限时；暂停时修改仍保持暂停。超时是否停留由「提交答案后直接下一个」决定。结束保留已保存的逐词记录，不补算完整分组成绩。

自定义语料

点击「自定义语料」按钮进入手动语料并展开编辑区；手动编辑原语料也会切换为自定义语料并保留输入。仅支持当前王璐听力语料库机考第二版内的单词和词组。用换行、中英文分号或逗号分隔，短语保留空格，重复项合并。开始时提示不存在、不属于所选组或缺音频的条目；没有可播放项则不开始。要计完整组成绩，重新选择原组且不修改语料。纯数字默认跳过，可在「设置」→「单词过滤」开启「播放纯数字」；纯符号始终跳过。

听音拼写

听音时可在当前词下方输入单词或词组，即时查看拼写对错；隐藏当前语料后仍可输入。拼写仅供练习，不计成绩、不进入错词本、不改变难度。播放间隔到点自动切词、手动上一个／下一个或重播时，输入与反馈一起清空；听音 0 秒播完立即切题，无限时等待手动切题。

本轮显示

本轮语料用紧凑词表展示全部条目；听音的当前语料和本轮语料可分别显示／隐藏，首次默认隐藏。听音时，在错误等级下方点击「内容展示」，选项随语料 content 字段自动生成，标题直接显示源 key（当前例如 meaning、example、note），默认全选；新增或改名后随源更新，旧选择无法匹配时恢复全选；当前词的内容先去掉首尾空格，再在按钮下方左对齐显示，切词后更新。空字符串或 null 保留标题、内容留空；取消全部勾选后显示「当前语料暂无所选内容」；选择在当前浏览器独立记忆，不进入学习备份。桌面练习卡片随内容增高时，本轮进度同步等高。听音和听写均可「隐藏本轮语料」，整份列表隐藏，标题与「显示本轮语料」入口保留；重新显示后，听写未作答词的拼写仍遮蔽，已作答反馈保留。收起「本轮进度」使整张卡片隐藏、练习区向右扩展，用「展开本轮进度」恢复。显隐选择会保存，不改变播放与计时；错词本的列表分页保持独立。

判题与自动推进

忽略大小写、首尾及连续空白，统一常见弯引号；仍须拼写正确。空提交不判错，有效提交后结果固定。「提交答案后直接下一个」位于「显示答案」与「暂停／继续练习」之间，默认开启，答对、答错和超时均立即切题，不展示本题反馈；关闭后答对自动、答错和超时手动继续。选项在当前浏览器记忆，不进入学习备份。主动点击「显示答案」始终记错并停留，须手动继续；显示答案不会触发自动下一题。真实单词、反馈及操作提前占位，本轮语料及进度仍可自行显示／隐藏，已答原词、对错标记和计数保持原有显示规则。完成后可「复练本轮错词」。

重播与暂停

需要再听时点击「重播」。暂停状态不接受提交；打开设置，或在原标签页查看操作说明、离开模块，都会暂停，关闭或返回后须主动继续。问号打开新标签前，请先主动暂停练习。

读取、保存与音频失败

启动时过滤缺音频条目，原组因此失去分组计分资格。顶部「读取失败」时可临时练习但不会保存，先「重试读取」；「重试读取复习设置」保留输入和待保存答案，成功前不按空设置排期。「尚未保存」时保留页面并「重试保存」，判题成功不等于保存成功。

答题详情与本次正确率

仅听写提供答题详情，听音不提供。清单按原题序展示单词、我的拼写和作答状态。答题详情、CSV「是否正确」和 AI「对错」统一为错误、未填写、答题超时、已查看答案、正确五种状态：已查看答案优先，其次答题超时，再次为空白未填写，其余按首次判题显示正确或错误。正确率以答对题数除以已答题数计算，未作答即跳过的题目不计入分母；已答题后来跳过音频仍保留详情并计入正确率，没有已答题时不表示取得有效成绩。超时或未答时显示答案会判错；已有结果后再显示答案只补查看标记，不重复计次。展示状态不改变首次成绩或已答题分母，即使首次答对后查看答案，正确率仍按原判题结果计算。详情仅保留在当前页面内存，刷新、切换分组或开始新一轮会清空，不进入完整备份；需要保留时先导出或复制。

答题 CSV 与 AI 诊断

「答题情况一键导出」使用 UTF-8 BOM，内容固定为单词、拼写单词、是否正确三列，仅含本次已答题。章节、分组和导出时间只放在文件名，时间使用北京时间并精确到秒；文件名取本轮实际来源，自定义语料与跨组复练明确区分，多章节或多分组使用范围说明。超时和查看答案不增加 CSV 列。发起下载后，到浏览器下载列表确认文件已保存；文件用于整理，不能通过「导入备份」恢复。「AI 一键诊断」仅复制雅思听力备考老师的诊断提示词、本次汇总、播放设置和逐题数据到剪贴板，不会在站内调用 AI；每题只包含原词、我的拼写、对错，不含序号及单独的超时／查看答案字段，「对错」使用与详情一致的五种状态。播放设置取本轮结束时最后生效的值，中途修改以最后值为准，结束后调整下一轮设置不改变本轮诊断。看到「已复制」后粘贴到 DeepSeek／ChatGPT，由站外 AI 分析拼写薄弱点、错误模式并给出改进建议；复制失败按页面提示重试，分析建议须自行核对。
