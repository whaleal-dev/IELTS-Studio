备份与本地资料

学习资料只保存在同一浏览器及访问地址；完整备份用于在需要时恢复四个学习模块与公共设置的已保存资料。

从哪里进入

打开顶部「设置」，进入「备份」，分别使用「下载备份」「自动备份」和「导入备份」。

操作步骤

  1. 先点击「下载备份」，看到发起下载提示后到浏览器下载列表核对当前资料的完整备份文件已保存。
  2. 需要定期备份时设置「自动备份」的天数，面板显示备份计划；网站打开且适合操作时才会发起下载，仍须到下载列表核对。
  3. 需要恢复时点击「导入备份」并选择完整备份 JSON，校验成功后出现「确认导入的备份」及当前与导入资料对比。
  4. 核对实际文件、备份时间与覆盖范围，再点击「恢复此备份」，页面出现最终确认区；导入为 0 条的模块也会替换当前资料。
  5. 按界面要求输入「恢复备份」，点击「确认恢复备份」，等待核验、恢复和页面重新加载。
  6. 重新打开相应模块核对词库、笔记、记录及设置；若恢复中断，按下方分支处理，不能仅凭文件校验通过认定恢复完成。

怎么用

在设置的「备份」中下载备份，或选择文件查看校验与覆盖范围后导入。备份最多 64 MiB、250000 条，不含音频、缓存、未保存内容和本轮临时结果。自动备份默认每 3 天，可选 1～7 天，只在网站打开且适合操作时发起文件下载。

结果与注意事项

恢复需输入「恢复备份」并最终确认，将替换全部学习资料与公共设置。成功核验后清理旧副本，当前版本不能一键撤回；想找回原资料须重新导入此前下载的备份。中断时按页面的继续、取消或完成恢复提示操作。

例子

例如：换浏览器，或把 localhost 换成 127.0.0.1，资料不会自动共享；端口、协议不同也分别保存，需要通过完整备份转移。自动下载发起不等于文件已落盘，请在浏览器下载列表确认；网站关闭时不会执行备份。

备份恢复与中断处理

  • 下载当前备份并核对文件已保存
  • 选择要恢复的完整备份并核对范围

    校验失败不会替换原资料，请按提示更换文件。

  • 输入恢复备份并最终确认

    恢复替换全部学习资料与设置，不与现有资料合并。

  • 切换前失败或中断：按提示继续或取消

    继续须使用上次的同一备份；若仍有导入预览，先点取消导入，才能确认取消本次恢复。中断后若原资料又被修改，继续恢复会被拒绝，须先取消本次恢复，再重新选择文件校验。

  • 切换后收尾失败：完成恢复

    此时备份已导入，请点击完成恢复进行核验与清理，不能沿用切换前的取消路径。

  • 恢复完成并核对资料

    成功后不能一键撤回；找回原资料须重新导入此前下载的备份。

文件内容与学习记录能否导入备份恢复
单词难点词 CSV筛选范围内难度大于 0 的词及相关学习数据；不含笔记，不是完整学习记录。不能通过导入备份恢复，只供查看和整理。
听力错词 CSV勾选或筛选语料、来源、错误等级、累计练习／正确／错误次数等；不是完整学习记录。不能通过导入备份恢复，只供查看和整理。
