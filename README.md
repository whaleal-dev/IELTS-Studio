# IELTS Studio

IELTS Studio 是一个面向雅思学习者的中文学习网站，提供词汇、听力、听力挖空、同义词、词表播放、本地音频播放与学习资源下载。无需注册账号，打开网页即可使用；个人词库、笔记和学习记录保存在当前浏览器中。

**在线使用：[IELTS Studio](https://docs.whaleal.com/IELTS-Studio/) 。**

[项目说明](https://docs.whaleal.com/IELTS-Studio/about/) · [操作说明](https://docs.whaleal.com/IELTS-Studio/help/) · [网站地图](https://docs.whaleal.com/IELTS-Studio/sitemap/) · [版本记录](CHANGELOG.md) · [本次发布信息](release.json)

## 可以做什么

| 模块 | 主要用途 | 在线入口 |
| --- | --- | --- |
| 单词 | 按章节和分组学习内置主题词汇或个人词库，使用单词卡片、选择释义和听写，记录笔记并查看统计 | [进入单词](https://docs.whaleal.com/IELTS-Studio/) |
| 听力 | 使用原声语料进行听音和听写，复练错词，查看完整分组练习成绩 | [进入听力](https://docs.whaleal.com/IELTS-Studio/listening/) |
| 听力挖空 | 选择 176 篇材料听原声填空，查看首次结果、揭晓与本轮错题，保存答卷并连接本地音频目录 | [进入听力挖空](https://docs.whaleal.com/IELTS-Studio/listening-cloze/) |
| 同义词 | 按组学习同义替换，导入 TXT／CSV 词库，搜索、循环播放与维护已有笔记 | [进入同义词](https://docs.whaleal.com/IELTS-Studio/synonyms/) |
| 单词播放 | 粘贴自己的英文词表，设置发音、顺序、重复次数及间隔，进行播放或逐词听写 | [进入单词播放](https://docs.whaleal.com/IELTS-Studio/word-player/) |
| 音频播放 | 混排本地录音与 CSV／TXT 词表，按文件设置发音、速度和循环，支持全局应用、排序与参数历史 | [进入音频播放](https://docs.whaleal.com/IELTS-Studio/audio-player/) |
| 资源下载 | 搜索学习材料，预览 TXT／JSON／CSV／Excel／PDF，下载单份文件或批量打包为 ZIP | [进入资源下载](https://docs.whaleal.com/IELTS-Studio/downloads/) |

单词与听力支持错题间隔复习：默认依次为 20 分钟、1 天、3 天、7 天、15 天、30 天，可以在设置中将阶段增减为三至十五个，并自定义各阶段间隔。实际答错会重置复习计划，到期后首次独立答对才推进；查看材料后的巩固作答不推进阶段。右上角「复习」提供到期任务入口。

全站提供快捷键、八套预设主题和自选主色。七个网站模块之间切换会保留已打开页面的状态，离开学习模块时暂停播放，返回后主动继续。电脑与手机均可使用；英文学习材料保持原文。

## 开始学习

1. 打开网站，选择单词或听力的章节、分组，进入学习；也可直接使用同义词或粘贴词表播放。
2. 如需个人词库，准备 CSV 或 TXT 文件。单词词库依次填写「单词、释义、音标、单词章节、单词分组」，使用英文逗号分隔；CSV 需要表头，TXT 不需要。页面提供可下载模板。
3. 功能旁的问号会在新标签页打开对应操作说明；首次使用可阅读 [个人词库导入](https://docs.whaleal.com/IELTS-Studio/help/words-import/) 和 [词表播放与听写](https://docs.whaleal.com/IELTS-Studio/help/player-wordlist/) 教程。
4. 在「设置」→「备份」定期导出完整学习记录，并在浏览器下载列表确认文件已保存。恢复前可预览备份内容，操作见 [完整备份与恢复教程](https://docs.whaleal.com/IELTS-Studio/help/backup/) 。

## 学习资料保存在什么地方

音频播放最多混排 100 份录音与 CSV／TXT 词表，词表提取英文单词和短语。两类合计记住最近 100 份参数历史，兼容读取旧 1000 份历史，按类型和文件元信息匹配并纳入完整备份。文件内容、顺序和进度仅临时保留，刷新需重新导入；文件不上传本站，浏览器语音可能联网。录音暂停保留时间，词表继续从当前词开头重读。

网站前端是静态应用，无需注册账号，默认把个人词库、笔记、错词、成绩与设置保存在当前网站来源的浏览器 IndexedDB 中。用户在「设置 → 备份」主动启用云备份后，网站会向独立后端单向上传已保存资料；开启或上传失败不代表已有完整云端副本，请核对「最近完整上传」。没有自动云端恢复或多设备同步，不同设备、浏览器、域名或端口之间不会自动共享；清除网站数据会失去本地资料和云备份凭据。

云备份包含已保存的词库、导入原文、笔记、学习记录、挖空答卷与设置，以及构建、来源网址和内置资料摘要；不包含音频、缓存、设备目录、未保存内容或云备份凭据。邮箱仅作联系登记，不是账号，也不能单独证明归属；请另行保管备份空间标识和恢复码，取回时由管理员核验后人工导出，再通过「导入备份」恢复。云端只保留当前副本；关闭上传保留已有云端内容，本站没有自助删除整个空间的入口，也未设置自动到期删除。具体操作、失败边界与凭据保管见 [云备份说明](https://docs.whaleal.com/IELTS-Studio/help/backup/#backup-cloud) 。

上传使用 HTTPS，服务端以 JSON 保存学习内容，管理员可通过私有导出流程读取；现有实现不提供端到端加密。已保存记录的删除须成功上传后才从云端当前值中移除，不能将清除本地数据理解为删除云端空间。

完整 JSON 备份用于迁移和恢复，包含听力挖空答卷与首次结果；难点词、错词 CSV 和挖空错题 TXT 仅用于查看和整理，不能替代完整备份。网页提示保存失败时，先保留页面与输入并重试，不要通过清除网站数据排障。网站升级不会把本地学习资料上传到发布仓库。

听力挖空的云端原声、手动文件和本地目录共用当前答卷。目录操作支持电脑 Chrome／Edge，关联不进入学习备份；手动文件刷新后需重新选择，目录按权限恢复，返回页面不自动播放。独立音频包下载是否开放以页面提示为准。

资源下载模块运行时读取独立托管的资料清单，资料更新与主站发版分开进行。资源页「贡献文件」提供邮件模板，附件需手动添加，文件由站长审核后上传。

## 开发与维护

项目使用 Vue 3、Vite 和 PrimeVue 4，构建为纯静态文件，通过 GitHub Pages 托管。主站采用 `/IELTS-Studio/` 基础路径，公开模块、教程及项目说明均可通过固定网址访问和刷新。

开发源码、启动命令、维护规范和部署流程属于开发仓库 `whaleal-dev/ielts`，访问需要相应仓库权限。本发布仓库的 `main` 分支不保存完整开发源码或内部审查材料；公开操作说明见上方站内链接。
